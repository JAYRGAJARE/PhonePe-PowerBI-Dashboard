# Project Documentation

## 1. Project Name
PhonePe Payment Insights Dashboard

## 2. Objective
Build an interactive Power BI dashboard for analyzing payment transactions and user behavior.

## 3. Dataset Statistics
- Users table: 107,658 rows
- Transactions table: 300,000 rows
- Transaction date range: 2024-01-01 to 2024-12-30
- Unique transaction users: 100,761
- Total transaction value: ₹3.47B

## 4. Services
- Recharge_Bills
- Money_Transfer
- Loans
- Insurance

## 5. Payment Status Distribution
- Successful: 287,993
- Failed: 9,980
- Wrong PIN: 700
- Server error: 692
- Insufficient amount: 635

## 6. Dashboard Components
- KPI Cards
- Month slicer
- Payment Status slicer
- Transactions Over Time
- Age Segment Contribution
- Service Transaction Value Analysis
- Top 5 Users by Transaction Value
- Weekday vs Weekend Usage
- Insights panel

## 7. Portfolio Learning
This project demonstrates the complete analytics flow:
**Dataset → Power Query → Data Model → DAX → Visualizations → Business Insights**
